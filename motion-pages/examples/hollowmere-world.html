Procedural

Trees, rocks and ruins are code

Bark, stone, leaves, grass blades and the forest floor are painted onto canvases at load; canopies are clouds of alpha-tested leaf cards that sway in a vertex shader; rocks are noise-displaced icosahedra. Seeded, so the weald is the same weald for everyone. 0 image requests

Click the ground and the wayfarer walks there. Reach a waystone and it lights. The HUD is the site's chrome — quest, minimap, vitality, hotbar — so the page feels like the game before you install it.
