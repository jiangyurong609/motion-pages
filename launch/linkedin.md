Most AI-generated landing pages share the same tell: Inter font, a purple
gradient, three identical feature cards. The model isn't the problem. The
missing piece is judgment, and judgment can be encoded.

I open-sourced motion-pages, a Claude Code skill that builds award-site-style
motion pages (foggy 3D worlds, liquid-glass shader typography, particle morphs)
as single HTML files. The part I care about most isn't the visuals. It's the
loop: the agent screenshots its own work at desktop, tablet and phone sizes,
reviews the screenshots against a design checklist, runs a pixel audit that
hunts blank frames, low contrast, dead motion and AI-slop patterns, and
iterates until the audit passes. Generation is cheap now; verification is the
product.

All nine demos on the site were built this way, and each one ships with the
complete prompt that produced it. MIT licensed, no build step, works with any
coding agent.

Demos: https://motion-pages.pages.dev
Repo: https://github.com/jiangyurong609/motion-pages

If you try a prompt and it gives you something ugly, send it to me. Failure
cases are how the skill gets better.
